# 19 — Final agent handoff format

When completing a stage, report:
1. **What changed:** routes/components and exact files, with feature summary.
2. **References used:** specific full-page image paths and any missing source imagery.
3. **CMS integration:** exact real OpenAPI operation IDs/endpoints; mock data explicitly labeled.
4. **SEO:** metadata, canonical, sitemap, robots, structured data and redirect results with evidence.
5. **Hashtags:** sample suggestion→review→PATCH flow and tests; never claim direct ranking benefit.
6. **Indexing:** sitemap and Search Console/IndexNow integration states, quotas, event logs; no false Google indexed claims.
7. **Global loading/performance:** screenshot, reduced-motion behavior, Web Vitals lab/field measurements.
8. **Visual QA:** actual vs reference full-page screenshots and diff paths for 1440/390; outstanding discrepancies.
9. **Tests:** exact commands and pass/fail output, not assumptions.
10. **Blockers:** missing media, credentials, domain, branch phone, unpublished backend APIs, and decisions needed.

Stop and request user approval at visual gates (home first, then each page family). Do not move on with a knowingly inaccurate layout without reporting it.

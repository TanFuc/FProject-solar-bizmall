# Backend contract reference snapshot

These files are copies of the previously delivered **BM SOLAR Backend API-First Documentation** contract, bundled for convenience. They are **design-time snapshots**, not proof of a running API. Before coding, compare them with the latest backend repository/OpenAPI and regenerate types from the authoritative live version.

- `backend-openapi-reference.yaml` — proposed NestJS Public/Admin/SEO REST contract.
- `page-blocks.schema.json` — typed CMS block schema reference.

Do not invent or assume webhook, published URL feed, redirects feed, or Search Console monitoring endpoints if absent. Propose an API-first change instead.
